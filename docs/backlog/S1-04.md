## Goal
Fetch and normalize Greenhouse job-board postings into `JobPosting`.

## Files
- `apps/api/app/integrations/ats/{base,greenhouse}.py`
- `apps/api/scripts/record_fixture.py (shared; create if absent)`
- `apps/api/tests/fixtures/greenhouse/*.json`
- `apps/api/tests/integrations/test_greenhouse.py`

## Spec
The adapter implements `JobSource`, is tested **only** against JSON fixtures in `tests/fixtures/<ats>/` (recorded once from live endpoints with a `--record` flag on a small script) with respx mocks, and **must verify field names against the recorded fixture rather than these notes**:
- Greenhouse: `GET https://boards-api.greenhouse.io/v1/boards/{token}/jobs?content=true`. `content` is **HTML-entity-escaped HTML**, so call `html.unescape` before parsing. location = `location.name`; posted = `updated_at` (there's no true publish date, so set `posted_at=None` and `source_updated_at=updated_at`); url = `absolute_url`. `exists()` = `GET /v1/boards/{token}` returns 200.

## Acceptance criteria
- the adapter maps its fixture to valid `JobPosting`s.
- 404 → raises `SourceNotFound`.
- 429/5xx → raises `SourceTransientError` (the caller retries).
- a malformed single job is skipped and logged without failing the batch.
- Definition of Done in AGENTS.md §4.

## Test plan
respx-mocked fixture → assert field mapping; 404 / 429 / 500 / malformed-job cases.

## Out of scope
DB writes, normalization beyond the adapter's field mapping (S1-07 owns parsing helpers).
