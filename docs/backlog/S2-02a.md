| Points | Model | Depends on | Sprint |

## Goal
A calibrated, injection-resistant scoring prompt with a measurable eval.

## Files
- `apps/api/app/matching/prompts/score_v1.md`
- `apps/api/app/matching/schemas.py (MatchOutput)`
- `apps/api/tests/evals/scoring_cases.jsonl`
- `apps/api/app/cli.py (eval command)`

## Spec
`matching/prompts/score_v1.md` (rubric_version="score_v1"). The system prompt treats the posting as **untrusted data inside `<job_posting>` tags** and ignores any instructions inside it. Output schema `MatchOutput{subscores{technical 0–35, experience 0–30, projects 0–20, preferences 0–15}, matched_skills[], missing_requirements[], required_skills[] (≤10, normalized lowercase), reasoning (≤80 words), recommended_action}`. score = sum, clamped to 0–100 in code. Eval set `tests/evals/scoring_cases.jsonl`: 30 real postings hand-labeled by the user (`expected_band: high|mid|low`), including 3 prompt-injection cases. `jt eval scoring` prints band accuracy and the threshold is ≥ 80%.

## Acceptance criteria
- Meets every requirement in **Spec**.
- Definition of Done in AGENTS.md §4.

## Test plan
`jt eval scoring --live` against the 30 labeled cases → ≥ 80% band accuracy; injection cases score ≤ 50.

Pipeline plumbing (S2-02b).
