| Points | Model | Depends on | Sprint |
|---|---|---|---|

## Goal
One morning summary instead of a stream of pings.

## Files
- `apps/api/app/workflows/digest.py`
- `apps/api/tests/workflows/test_digest.py`

## Spec
cron `TZ={prefs.timezone} 0 8 * * *` → in-app and push summary: new high matches (≥ 75) since the last digest, queued-but-not-applied older than 3 days, applications with no response after 21 days, yesterday's LLM spend, and sources disabled.

- Definition of Done in AGENTS.md §4.

## Test plan

## Out of scope
