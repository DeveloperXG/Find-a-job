## Goal
Every table in ARCHITECTURE.md → Database schema exists with constraints and indexes.

## Files
- `apps/api/app/models/**`
- `apps/api/app/db.py`
- `apps/api/migrations/** (alembic init + 0001_initial)`
- `apps/api/alembic.ini`
- `apps/api/tests/conftest.py`
- `apps/api/tests/models/**`

## Spec
SQLAlchemy 2.0 typed `Mapped[]` models for every table in *Database schema* (`docs/ARCHITECTURE.md`), Postgres enums as `sa.Enum(..., native_enum=False)` (string + CHECK, easier migrations), async session factory in `db.py`, `0001_initial` autogenerated then hand-reviewed. Test fixture: a transactional `db_session` with rollback per test against a `jt_test` database.

## Acceptance criteria
- `alembic upgrade head` and `downgrade base` both run clean, and a round-trip insert/select test passes for each model.
- Definition of Done in AGENTS.md §4.

## Test plan
Round-trip insert/select per model; unique-constraint violation tests for `job_sources(ats, token)`, `jobs(source_id, external_id)`, the `job_matches` cache key, `applications.job_id` and `notifications.dedupe_key`.

## Out of scope
Repositories/services, API routes.
