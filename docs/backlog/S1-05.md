## Goal
Fetch and normalize Lever postings (US + EU regions) into `JobPosting`.

## Files
- `apps/api/app/integrations/ats/lever.py`
- `apps/api/tests/fixtures/lever/*.json`
- `apps/api/tests/integrations/test_lever.py`

## Spec
The adapter implements `JobSource`, is tested **only** against JSON fixtures in `tests/fixtures/<ats>/` (recorded once from live endpoints with a `--record` flag on a small script) with respx mocks, and **must verify field names against the recorded fixture rather than these notes**:
- Lever: `GET https://api.lever.co/v0/postings/{token}?mode=json` (if that returns 404, retry `api.eu.lever.co`, and persist which region worked in `raw["_region"]`). title = `text`; `categories.location` / `allLocations` / `commitment` / `team`; `workplaceType`; `descriptionPlain` + `lists[]` + `additionalPlain` concatenated for the text; `createdAt` is **epoch ms**; `salaryRange` → Compensation; `hostedUrl` / `applyUrl`.

## Acceptance criteria
- the adapter maps its fixture to valid `JobPosting`s.
- 404 → raises `SourceNotFound`.
- 429/5xx → raises `SourceTransientError` (the caller retries).
- a malformed single job is skipped and logged without failing the batch.
- Definition of Done in AGENTS.md §4.

## Test plan
respx-mocked fixture → field mapping; US 404 → EU fallback; epoch-ms conversion; error cases.

## Out of scope
DB writes.
