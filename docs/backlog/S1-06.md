## Goal
Fetch and normalize Ashby postings into `JobPosting`.

## Files
- `apps/api/app/integrations/ats/ashby.py`
- `apps/api/tests/fixtures/ashby/*.json`
- `apps/api/tests/integrations/test_ashby.py`

## Spec
The adapter implements `JobSource`, is tested **only** against JSON fixtures in `tests/fixtures/<ats>/` (recorded once from live endpoints with a `--record` flag on a small script) with respx mocks, and **must verify field names against the recorded fixture rather than these notes**:
- Ashby: `GET https://api.ashbyhq.com/posting-api/job-board/{token}?includeCompensation=true`. Skip `isListed == false`. Fields: `descriptionPlain` / `descriptionHtml`, `location` + `secondaryLocations`, `workplaceType`, `employmentType`, `publishedAt`, `jobUrl`, `applyUrl`, `compensation`.

## Acceptance criteria
- the adapter maps its fixture to valid `JobPosting`s.
- 404 → raises `SourceNotFound`.
- 429/5xx → raises `SourceTransientError` (the caller retries).
- a malformed single job is skipped and logged without failing the batch.
- Definition of Done in AGENTS.md §4.

## Test plan
respx-mocked fixture → field mapping; `isListed=false` skipped; compensation mapping; error cases.

## Out of scope
DB writes.
