## Goal
Reject ineligible jobs for free before any LLM call, with explainable reason codes.

## Files
- `apps/api/app/matching/filters.py`
- `apps/api/app/api/preferences.py`
- `apps/api/app/cli.py (filter command)`
- `apps/api/tests/matching/test_filters.py`
- `apps/api/tests/api/test_preferences.py`

## Spec
Preferences JSON (Pydantic `Preferences`): `role_families: list[RoleFamily]`, `seniorities: list[Seniority]`, `countries: list[str]`, `workplace: list[WorkplaceType]`, `cities: list[str]` (only applied to onsite/hybrid roles), `needs_sponsorship: bool`, `min_base_salary_usd: int|None` (only applied when comp is known, so unknown comp passes), `employment_types`, `max_required_yoe: int=3`, `exclude_companies: list[uuid]`, `exclude_title_keywords`, `require_any_keywords`, `daily_quota: int=10`, `timezone: str`, `company_cooldown_days: int=30`, `llm_daily_budget_usd: Decimal=1.00`. `filters.evaluate(job, prefs) -> (passed: bool, reasons: list[str])`. Each rule is a small named function, and reasons are machine codes (`seniority_mismatch`, `no_sponsorship`, …). Unknown values **pass** except for `needs_sponsorship` combined with the `no_sponsorship` flag. API: `GET/PUT /preferences` (increments the profile version). `jt filter --pending`. **Defaults seeded from *Target roles* (`docs/ARCHITECTURE.md`):** `role_families=[sde,mle,aie,research,data_science,robotics,cv]`, `seniorities=[intern,new_grad,junior,unknown]`, `employment_types=[full_time,internship,fellowship]`, `max_required_yoe=3`.

## Acceptance criteria
- a rule-by-rule test table.
- changing preferences re-filters all open jobs.
- Definition of Done in AGENTS.md §4.

## Test plan
One parametrized case per rule (pass and fail), plus the unknown-value-passes cases.

## Out of scope
Prescore and LLM scoring (S2-02b).
