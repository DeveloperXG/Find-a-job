## Goal
A single, metered, budget-capped path to any LLM.

## Files
- `apps/api/app/integrations/llm/{anthropic,fake,budget}.py`
- `apps/api/app/config.py (LLM_* settings + pricing table)`
- `apps/api/tests/integrations/test_llm.py`

## Spec
`AnthropicProvider` implements `LLMProvider`: tool-use structured output (a single tool whose `input_schema` is the Pydantic JSON schema, with `tool_choice` forced), a `cache_control` breakpoint after `cached_context`, retries with exponential backoff on 429/529/5xx (max 3), and Pydantic validation with **1 repair retry** (the validation error is sent back to the model). `FakeProvider` returns canned objects for tests. The pricing table lives in `config.py` (USD per MTok per model, **filled in from the current Anthropic pricing page at implementation time**). Every call writes to `llm_calls`. `BudgetGuard.check(task)` sums today's `cost_usd` in the user's timezone and raises `BudgetExceeded` once it exceeds `llm_daily_budget_usd`.

## Acceptance criteria
- fake-provider tests cover the repair retry, budget exceeded and cost accounting.
- one opt-in live test is behind `-m live`.
- Definition of Done in AGENTS.md §4.

## Test plan
FakeProvider + respx-mocked Anthropic responses: valid output, invalid → repair → valid, invalid twice → error, 429 retry, budget exceeded.
