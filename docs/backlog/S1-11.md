## Goal
A navigable, themeable dashboard shell with a first read-only job feed.

## Files
- `apps/web/app/(app)/layout.tsx`
- `apps/web/app/(app)/feed/page.tsx`
- `apps/web/app/globals.css`
- `apps/web/components/{sidebar,topbar,theme-toggle}.tsx`
- `apps/web/lib/api.ts`
- `packages/contracts/**`
- `justfile (gen-types)`

## Spec
App shell: left sidebar (Feed, Pipeline, Resumes, Companies, Runs, Settings), top bar with a search box and a notifications bell, and a dark-mode toggle. **All colors, radii and spacing come from CSS variables in `globals.css`** (`--bg`, `--fg`, `--muted`, `--accent`, `--score-high/med/low`), so the future design direction is a token swap. `lib/api.ts` = openapi-fetch client typed from `packages/contracts/schema.d.ts`. Feed v0 is a server-paginated table: title, company, location, workplace, posted date, filter status.

## Acceptance criteria
- renders 500 rows smoothly.
- Lighthouse accessibility ≥ 90.
- Definition of Done in AGENTS.md §4.

## Test plan
Playwright smoke: shell renders, sidebar navigation works, the feed table renders mocked rows, and dark-mode toggle swaps tokens.

## Out of scope
Scores, filters UI, job detail (S2-08).
