# S2-03 — Jobs/matches API

| Points | Model | Depends on | Sprint |
|---|---|---|---|
| 3 | Sonnet | S1-08 | 2 — Intelligence & tracking |

## Goal
Fast, filterable, ranked feed API.

## Files
- `apps/api/app/api/jobs.py`
- `apps/api/tests/api/test_jobs.py`

## Spec
`GET /jobs?min_score&role_family&workplace&company_id&state=open&user_state&sort=score|posted|first_seen&q&cursor&limit` joins the latest match and excludes duplicates and dismissed jobs by default. `GET /jobs/{id}` returns the job, match and application (if any). `POST /jobs/{id}/save|dismiss|restore`. Keyset pagination on (sort key, id).

## Acceptance criteria
- p95 < 150 ms on 20k jobs (seed with polyfactory).
- Definition of Done in AGENTS.md §4.

## Test plan
httpx AsyncClient against the app; seeded 20k rows for the perf test (marked `@pytest.mark.slow`).

## Out of scope
Full-text search beyond `ILIKE` on title/company.
