## Goal
Pure parsing helpers that turn messy posting text into structured, filterable attributes.

## Files
- `apps/api/app/ingestion/normalize.py`
- `apps/api/tests/ingestion/test_normalize.py`

## Spec
(`ingestion/normalize.py`, pure functions, table-driven tests with ≥10 cases each):
- `html_to_text(html)`: BeautifulSoup; strip scripts/styles; turn `<li>` into "- " lines; collapse whitespace; **truncate to 12,000 chars** with an ellipsis marker.
- `normalize_title(title)`: lowercase; strip the req-ID, location and "(Remote)" suffixes; map I/II/III to 1/2/3.
- `infer_seniority(title, text)`: ordered regexes (intern → new grad / "university" / "early career" → staff/principal/distinguished → senior/sr → manager/head/director → "junior"/"associate"/"I"/"1" → mid). Unknown if nothing matches.
- `infer_role_family(title, dept)`: ordered keyword map, first match wins (research scientist/research engineer/resident/fellow → research; robotics/autonomy → robotics; computer vision/perception → cv; machine learning/ML/applied scientist → mle; AI engineer/applied AI/LLM/GenAI/agents/evaluation/AI safety → aie; data scientist → data_science; data engineer/analytics engineer → data_eng; software/backend/frontend/full-stack/SWE/SDE/python developer/platform → sde). Test cases must include all 20 target titles from *Target roles* (`docs/ARCHITECTURE.md`).
- `infer_employment_type(...)`: "fellow", "fellowship", "resident", "residency" → `fellowship`; "intern", "co-op" → `internship`.
- `extract_min_yoe(text)` → int|None for the `yoe_too_high` filter.
- `parse_locations(raw, workplace_hint)`: split on ";", "|", " or ", "/"; detect remote ("Remote", "Anywhere", "Remote - US"); extract a country (US state abbreviations → US); return `(locations, workplace_type, countries)`.
- `parse_compensation_from_text(text)`: regex for `$120,000 - $160,000`, `$120k–$160k`, `$55/hr`, and EUR/GBP/CAD symbols. Used only when the ATS gives no structured comp.
- `detect_work_auth_flags(text)`: returns flags such as `no_sponsorship`, `us_citizen_required`, `security_clearance`, `sponsorship_available`.
- `content_hash(...)` and `fingerprint(...)` as defined in the schema.

## Acceptance criteria
- Meets every requirement in **Spec**.
- Definition of Done in AGENTS.md §4.

## Test plan
Table-driven pytest (`@pytest.mark.parametrize`), ≥ 10 cases per function, including all 20 target titles.

## Out of scope
