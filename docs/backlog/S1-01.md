## Goal
A fresh clone boots Postgres, the Inngest dev server, an empty API, worker and web app, and runs CI.

## Files
- `apps/api/pyproject.toml`
- `apps/api/app/{main,worker,config,db,cli}.py (stubs)`
- `apps/api/tests/test_smoke.py`
- `apps/web/** (create-next-app + shadcn init)`
- `infra/docker-compose.yml`
- `justfile`
- `.env.example`
- `.github/workflows/ci.yml`
- `.gitignore`
- `pnpm-workspace.yaml`
- `package.json`

## Spec
`uv init apps/api` (Python 3.12). Dependencies: fastapi, uvicorn[standard], sqlalchemy[asyncio]>=2, asyncpg, alembic, pydantic-settings, httpx, beautifulsoup4, lxml, inngest, anthropic, typer, typst, jinja2, structlog. Dev dependencies: pytest, pytest-asyncio, respx, ruff, mypy, polyfactory. `pnpm create next-app apps/web` (TS, App Router, Tailwind, ESLint) plus `shadcn init`. `infra/docker-compose.yml`: postgres:16 (port 5432, volume) and `inngest/inngest` dev server (`inngest dev -u http://host.docker.internal:8001/api/inngest`, port 8288). `justfile` targets: `up`, `api` (port 8000), `worker` (port 8001), `web` (port 3000), `migrate`, `test`, `lint`, `gen-types`, `ingest`. `.env.example` lists every variable in `config.py`. GitHub Actions `ci.yml` runs Postgres as a service, then ruff, mypy, pytest, `pnpm lint`, `tsc --noEmit`.

## Acceptance criteria
- fresh clone → `just up && just migrate && just test` passes on Windows (PowerShell + Git Bash) and Linux CI.
- Definition of Done in AGENTS.md §4.

## Test plan
`just test` runs one smoke test (`GET /health` → 200) and a web build. CI runs on the PR.

## Out of scope
Any domain code, models or real endpoints.
