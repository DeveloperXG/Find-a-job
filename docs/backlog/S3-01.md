| Points | Model | Depends on | Sprint |

## Goal
Protect personal data before deployment.

## Files
- `apps/api/app/auth.py`
- `apps/api/app/api/auth.py`
- `apps/web/middleware.ts`
- `apps/web/app/login/**`
- `tests`

## Spec
Single-user auth: argon2 hash in env, `POST /auth/login` → httpOnly SameSite=Lax signed session cookie (itsdangerous), FastAPI dependency on all routes, Next.js middleware redirect, login rate limit 5/min

## Acceptance criteria
- Meets every requirement in **Spec**.
- Definition of Done in AGENTS.md §4.

## Test plan
Login success/failure, rate limit, every router requires auth (parametrized over the route table).

## Out of scope
Multi-user, OAuth login.
