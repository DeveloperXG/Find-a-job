## Goal
Browse ranked jobs, inspect a match, and move applications through the pipeline.

## Files
- `apps/web/app/(app)/feed/**`
- `apps/web/app/(app)/jobs/[id]/**`
- `apps/web/app/(app)/pipeline/**`
- `apps/web/components/{score-badge,job-card,filter-bar,kanban,event-timeline}.tsx`
- `apps/web/tests/**`

## Spec
- **Feed**: card list with a score badge (color token by band), title, company, location chip, comp, posted age, top 3 matched skills and top 2 missing requirements. Filter bar (score slider, role family, workplace, company). Keyboard shortcuts: `j/k` to move, `s` to save, `d` to dismiss, `enter` to open.
- **Job detail** (`/jobs/[id]`): two columns. Left: description. Right: score breakdown bars, reasoning, missing requirements, plus "Tailor resume", "Add to queue" and "Open posting ↗" buttons.
- **Pipeline** (`/pipeline`): kanban columns Queued · Applied · Next Steps · Offer · Rejected · Archived/Other. Dragging calls PATCH status; an invalid transition shows a toast and snaps back. The card drawer shows the event timeline.

## Acceptance criteria
- Playwright component smoke test per page.
- optimistic updates roll back on error.
- Definition of Done in AGENTS.md §4.

## Test plan
Playwright smoke per page against a mocked API; optimistic rollback test.
